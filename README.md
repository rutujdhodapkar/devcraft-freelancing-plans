# DevCraft Freelancing Plans

React/Vite landing page for DevCraft project development and technical support plans for diploma students.

## Plans
- Starter — ₹15,000
- Professional — ₹20,000
- Complete — ₹30,000
- Custom — scoped quotation

## Local development
```bash
npm install
npm run dev
```

## GitHub Pages
The repository includes a GitHub Actions workflow at `.github/workflows/deploy.yml`.

In GitHub, open **Settings → Pages** and set **Source** to **GitHub Actions** if it is not already selected. Pushes to `main` then build and deploy automatically.
